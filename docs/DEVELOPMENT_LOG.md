# 开发日志

## 2026-06-01：0.1.5 需求整理 - 多数量传送与界面简化

发布版本：`0.1.5`

### 本次新增需求

1. 在“搜索链接”模块新增“购买数量”，最大值 999。
2. 添加搜索后，软件按购买数量累计自动传送次数；达到目标数量后自动暂停该搜索。
3. 检测到结果后，需要识别每条结果右侧状态：
   - `Travel to Hideout`：可点击，按页面从上到下依次点击。
   - `Traveling!` / 已点击状态：忽略该行。
   - `Unignore Player`：该卖家已被用户忽略，忽略该行。
4. 隐藏“搜索链接”模块里的“结果选择器”，继续使用默认选择器，不让普通用户配置。
5. 新增“传送下个仓库间隔（秒）”，用于多个购买目标时控制下一次点击 `Travel to Hideout` 的等待时间。
6. “检查间隔（秒）”改名为“搜索市集间隔（秒）”。
7. “搜索市集间隔（秒）”“购买数量”“传送下个仓库间隔（秒）”三项在同一行，从左到右排列。
8. “搜索 URL”改名为“设置好搜索条件的集市网址复制到这里”。
9. 第一版监控列表最多 5 个搜索，需要重新设计列表空间。
10. 新增可自定义直传快捷键，默认 `F8`，只支持单个 `F1` 到 `F12`，不支持组合键。
11. 用户第一次自动传送后，按直传快捷键可跳过等待时间，立即点击下一条可用 `Travel to Hideout`。
12. 直传后重新按“传送下个仓库间隔”开始计时，默认间隔改为 30 秒。
13. 间隔输入说明改为“按F8直传下个卖家仓库，或按下列间隔传送（秒）”，自定义快捷键后说明同步变化。

### 当前实现现状

- 当前版本只支持发现结果后打开页面并点击第一个可见的 `Travel to Hideout`。
- 当前没有“购买数量”字段，也没有购买进度记录。
- 当前没有逐个点击多个结果的队列逻辑。
- 当前“结果选择器”显示在界面上，用户容易误改。
- 当前监控列表卡片会显示完整 URL，5 个搜索时会占用较多空间。
- 当前没有全局直传快捷键。

### 本次建议方案

- 数据模型新增：
  - `targetQuantity`：目标购买数量，1 到 999。
  - `purchasedQuantity`：已自动点击传送次数。
  - `travelDelaySeconds`：点击下一个仓库的间隔秒数。
  - `travelHotkey`：直传快捷键，默认 `F8`。
- 自动传送逻辑改为：
  - 每次打开搜索页后扫描结果行。
  - 跳过文本含 `Traveling!` / `Teleporting!` / `Unignore Player` 的行。
  - 只点击仍显示 `Travel to Hideout` 的行。
  - 按页面从上到下顺序点击。
  - 每点击一次累计 `purchasedQuantity += 1`。
  - 达到 `targetQuantity` 后自动暂停该搜索。
  - 每次点击后进入等待，等待到期或用户按直传快捷键后点击下一条。
  - 如果用户按快捷键直传，下一次等待从本次传送后重新计时。
- UI 调整：
  - “搜索链接”模块改为横跨工作区顶部，保证三项数字参数可以一排显示。
  - 隐藏“结果选择器”，保留默认值。
  - 监控列表改为紧凑卡片，只显示名称、状态、购买进度、间隔、最近检查时间和操作按钮。
  - 长 URL 不在卡片里完整显示，避免撑开列表。
  - 监控列表区域固定高度并支持内部滚动，最多 5 个搜索不需要缩小主窗口。
  - 新增“直传快捷键”输入框；只接受 `F1` 到 `F12`。

### 需要确认的产品口径

- “购买足够数量”在软件里只能可靠理解为“已自动点击传送次数达到购买数量”。软件无法知道玩家是否真正完成交易。
- 默认“传送下个仓库间隔（秒）”按最新需求设为 30 秒。
- “购买数量”默认建议为 1。
